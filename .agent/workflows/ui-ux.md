# Workflow: /ui-ux

Activa y ejecuta las directrices de la skill `erp-uiux-design-system` ubicada en `.agents/skills/erp-uiux-design-system/SKILL.md`.

## Objetivo
Diseñar, implementar o refactorizar vistas y componentes UI del ERP bajo estándares profesionales de diseño empresarial, accesibilidad WCAG AA, data tables de alta densidad y micro-interacciones.

## Pasos de Ejecución
1. **Verificar el Lenguaje de Tokens y Tema**:
   - Respetar paletas semánticas (Slate/Indigo/Emerald/Cyan) y soporte para temas Light, Dark y Obsidian Cyberpunk.
2. **Construir Componentes Atómicos Reutilizables**:
   - Implementar KPI Cards con sparklines, modales accesibles con backdrop blur, badges semánticos y empty states ilustrados.
3. **Optimizar Tablas de Datos (Data Tables)**:
   - Añadir cabeceras fijas (`sticky top-0`), ordenamiento interactivo, números tabulares y paginación fluida.
4. **Verificar Micro-animaciones y Feedback**:
   - Integrar transiciones CSS sutiles y alertas contextuales consistentes con SweetAlert2.
