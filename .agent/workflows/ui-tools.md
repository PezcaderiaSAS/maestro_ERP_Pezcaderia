# Workflow: /ui-tools

Consulta recursos, generadores de paletas, tipografías y componentes visuales curados.

## Argumentos:
```bash
/ui-tools <categoria> [--query <termino>]
```
Categorías: `colors`, `typography`, `shadows`, `tables`, `modals`, `styleguides`.

## Fases de Ejecución:
1. **Resolución de Recursos:** Identifica la mejor herramienta o token disponible para el requerimiento.
2. **Generación de Código:** Devuelve la clase de Tailwind o snippet React correspondiente.

Consulta `.agents/skills/ui-ux-ecosystem/SKILL.md` para el catálogo completo.
