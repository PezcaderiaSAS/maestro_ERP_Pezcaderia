# Ruflo Agent Orchestration Integration

Este skill integra las herramientas de orquestación multi-agente y coordinación de swarms de `tools/ruflo`.

## Cuándo usar
Utiliza este skill cuando necesites:
- Coordinar múltiples agentes especializados de forma paralela en flujos complejos (diseño, codificación, revisión, testing).
- Configurar Ruflo como un servidor Model Context Protocol (MCP) para habilitar herramientas compartidas y memoria adaptativa.
- Configurar pasarelas de seguridad y memoria federada para comunicaciones entre agentes.

## Cómo usar
Consulta `tools/ruflo/` para ejecutar los scripts de orquestación y levantar el servidor MCP de Ruflo localmente.
