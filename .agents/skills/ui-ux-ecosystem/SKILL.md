# UI/UX Ecosystem & Curated Resources Skill

Esta habilidad consolida las mejores fuentes abiertas de la industria para diseño visual, patrones de componentes y guías de estilo corporativo.

---

## 1. Matriz de Colecciones de Recursos Integradas

| Colección / Fuente | Enfoque Principal | Utilidad en MaestroPescaderia ERP |
| :--- | :--- | :--- |
| **Penpot** | Prototipado y layouts Flex/Grid abiertos | Estructuras de pantallas y maquetación responsiva |
| **Awesome-Design-MD** (`voltagent`) | Especificaciones de diseño en Markdown | Mantenimiento y derivación de tokens en `DESIGN.md` |
| **Awesome-Design-Tools** | Herramientas de color, tipografía y sombras | Generadores de paletas HSL y contrastes WCAG |
| **Awesome-AI-Tools-for-UI** | Modelos y prompts para generación de UI | Templates para Google Stitch y Gemini UI |
| **Awesome-UI** | Librerías de componentes y micro-animaciones | Referencias para modales, tablas y menús táctiles |
| **Awesome-Styleguides** | Manuales de identidad corporativa | Estándares de consistencia visual en marca y tono |

---

## 2. Invocación

```bash
/ui-tools <categoria> [--query <termino>]
```
Categorías soportadas: `colors`, `typography`, `shadows`, `tables`, `modals`, `styleguides`.
