# Recursos de Desarrollo Web y Diseño

Este skill permite al asistente consultar recursos de desarrollo web y utilidades del repositorio local `tools/recursos`.

## Cuándo usar
Utiliza este skill cuando necesites encontrar herramientas externas para:
- **Diseño y Multimedia**: Iconos (Tabler Icons, Font Awesome), fuentes (Google Fonts), ilustraciones (unDraw, Freepik) y fotos (Unsplash, Picsum Photos).
- **CSS y Estilos**: Recursos de Tailwind, generadores de sombras o animaciones.
- **Visualización de Datos**: Librerías de gráficas como Chart.js o D3.js.
- **APIs de Prueba**: JSONPlaceholder o fakeJSON.
- **Herramientas de Base de Datos**: Recursos de bases de datos.

## Cómo buscar
Para encontrar recursos específicos, lee el archivo principal `tools/recursos/README.md` o los archivos en las subcarpetas de `tools/recursos/`.
