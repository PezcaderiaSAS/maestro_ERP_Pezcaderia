# Everything Claude Code (ECC) Integration

Este skill integra las guías de optimización de agentes, estándares de equipo e instrucciones personalizadas de `tools/ecc`.

## Cuándo usar
Utiliza este skill cuando necesites aplicar directrices de ECC para:
- Estructuración de tareas y prompts de agentes de IA.
- Configurar reglas de seguridad (`AgentShield`) o persistencia de memoria.
- Integrar estándares de TDD o revisión de código automáticos en tu flujo.

## Cómo usar
Consulta la documentación local en `tools/ecc/` para buscar plantillas de prompts o configuraciones del sistema.
