# GitHub Spec Kit: Spec-Driven Development (SDD)

Este skill define la metodología de desarrollo estructurada basada en especificaciones y planes técnicos de `tools/spec-kit`.

## Cuándo usar
Utiliza este skill cuando necesites:
- Definir la especificación funcional ("El Spec") de una nueva característica.
- Elaborar el diseño técnico o de arquitectura ("El Plan") antes de escribir código.
- Desglosar tareas atómicas ("Las Tareas") para que un agente de IA las ejecute secuencialmente.

## Ciclo de Trabajo SDD
1. **Constitución**: Define los principios no negociables del proyecto.
2. **Spec**: Define el "qué" y el "por qué".
3. **Plan**: Define la arquitectura y el diseño técnico.
4. **Tasks**: Lista de tareas atómicas (en `task.md`).
5. **Implementación y Verificación**: Codificación paso a paso y comprobaciones de calidad.
