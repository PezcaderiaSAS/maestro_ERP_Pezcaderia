# GitNexus Code Intelligence

Este skill proporciona acceso a utilidades y documentación de mapeo de bases de código estructuradas en forma de grafos de dependencia de `tools/gitnexus`.

## Cuándo usar
Utiliza este skill cuando necesites:
- Mapear la arquitectura del código y detectar dependencias de módulos.
- Conocer la cadena de llamadas de funciones o componentes en la base de código.
- Analizar el impacto ("blast radius") de cambios estructurales antes de realizarlos.

## Uso
Consulta `tools/gitnexus/` para ejecutar los scripts de análisis y generación de bases de conocimiento local de código.
